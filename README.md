# React Native Todo App

A simple, clean, and minimalist Todo list application built with React Native and Expo. Easily add, manage, and remove tasks with a user-friendly interface.

## Features

- Add new tasks
- Delete tasks with a single tap
- Clean and intuitive UI
- Built with React Native for cross-platform compatibility

## Technologies Used

- React Native
- Expo
- React Hooks (useState)
- React Native Paper

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the application: `npm start`
4. Use Expo Go app to scan the QR code and run on your device
